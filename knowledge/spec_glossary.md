# Spec glossary — house Hebrew terms

The copywriter uses these names for spec rows and adds a line whenever it coins a new one, so
the whole store stays consistent. Prefer terms already used by live items (`category-examples`).

| English | Hebrew (store) | Unit / format |
|---|---|---|
| Model | דגם | as written by the manufacturer |
| Finish / Colour | גימור / צבע | Hebrew colour name |
| Frequency response | תגובת תדרים | `47Hz – 45kHz (±3dB)` |
| Sensitivity | רגישות | `85dB (2.83V/1m)` |
| Nominal impedance | עכבה נומינלית | `8Ω` |
| Recommended amplifier power | הספק מגבר מומלץ | `40–100W` |
| Output power | הספק יציאה | `2 × 100W @ 8Ω` |
| Drivers | רמקולים / יחידות | `25mm טוויטר + 130mm וופר` |
| Crossover frequency | תדר הצלבה | `2.1kHz` |
| Inputs | כניסות | list |
| Outputs | יציאות | list |
| Connectivity / Streaming | קישוריות | list |
| Dimensions (H×W×D) | מידות (ג×ר×ע) | `302 × 200 × 280 מ"מ` |
| Weight | משקל | `7.8 ק"ג` (per unit / pair — say which) |
| Power consumption | צריכת חשמל | `W` |
| Channels | ערוצים | `7.2` |
| Dolby Atmos / DTS:X layout | פריסת Dolby Atmos / DTS:X | `5.2.2` |
| Speaker impedance (supported range) | עכבת רמקולים נתמכת | `4–16Ω` |
| HDMI inputs / outputs | HDMI | `4 כניסות / 2 יציאות (Main Out עם eARC, Sub Out)` |
| Audio inputs | כניסות שמע | `3 × RCA אנלוגי, 1 × אופטי, ...` |
| Streaming services / multi-room | סטרימינג | list of services/platforms |
| THX certification | הסמכת THX | `THX Certified Select` |
| Multi-zone | אזורים | `Zone 2 מוגבר ...` |
| Output power (AV receiver, 230V) | הספק יציאה | `7 × 135W @ 6Ω (1kHz, 1% THD, ערוץ אחד פעיל, IEC) — דגם 230V` — always with conditions |
